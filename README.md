# ⚡ AuraFlow — Interactive Creative & Data Flow Studio

A modern, high-performance, visually stunning React JS application featuring interactive data-flow node graphs, dynamic glassmorphic UI, customizable color palettes, user authentication, and ambient generative focus soundscapes.

---

## 🌟 Key Features

- **📥 DataFlow Studio (Interactive Node Engine)**: Drag-and-drop interactive node graph supporting Inputs, Processors, AI Models, and Output Vaults with live SVG Bezier packet animations and real-time telemetry logs.
- **🎨 5 Aesthetic Theme Palettes**: Instant live theme switching (*Cyber Neon*, *Aura Sunset*, *Bioluminescence*, *Deep Space*, *Nordic Slate*) dynamically updating CSS Custom Properties.
- **🌌 Interactive Canvas Background**: HTML5 particle mesh canvas that tracks mouse cursor speed and spotlight distance.
- **🔐 User Authentication & Profiles**: Login/Signup modal with 1-Click Demo Architect access, user levels, streaks, efficiency stats, and customizable profile bios.
- **📊 Telemetry Analytics Dashboard**: System health indicators and SVG gradient load charts for throughput monitoring.
- **📋 Task Matrix**: Priority-tagged task board with interactive completion particle bursts.
- **🎵 Ambience Sound Generator**: Browser-native Web Audio API synthesizer for generative focus audio.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or `yarn`

### Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/hharies-04/Auraflow-React.git
   cd Auraflow-React
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```
